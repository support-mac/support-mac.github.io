# eleectrum landing page

Responsive static landing page concept for GitHub Pages.

## Deploy
1. Create a GitHub repository (for a user site, name it `USERNAME.github.io`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages** and select **Deploy from a branch → main → /(root)**.
4. Save and wait for the Pages build.

## Before publishing / advertising
- Replace sample contact address (`support@example.com`) and add accurate legal company identity.
- Add genuine Privacy and Terms pages; current footer links are placeholders.
- Connect download, docs, and support links only to real, verified resources.
- Remove or correct any claim that does not accurately describe your actual product.
- This template does not guarantee Google Ads approval. Crypto-wallet ads may be subject to Google Ads certification, country, product-type, and other policy restrictions. Check current Google Ads policies before advertising.
- The interface balance and transactions are illustrative, not real account data.
